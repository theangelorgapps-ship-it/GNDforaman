Five concrete gaps remain in [Phase 2](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/docs/launch/PLAN.md:151>). These are design findings from read-only source inspection, not runtime verification.

1. **Reusing Modal does not guarantee focus restoration.** The name input uses `autoFocus`, but Modal captures `document.activeElement` afterward in an effect. It can capture the input inside the dialog rather than its opener; closing then targets an unmounted element. Specify initial focus and restoration to a surviving trigger, including Settings → Edit name → close. Evidence: [Modal.tsx:33](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/components/Modal.tsx:33>), [App.tsx:382](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/App.tsx:382>).

2. **The primary Saved readings journey lacks a history contract.** Profile opens Saved through `openLibrary("Saved")`, which changes React state without updating the URL. The address remains `#/profile`; refreshing returns to Profile, and browser Back can skip the Saved view. Phase 2 should define URL, refresh, and Back behavior for Profile → Saved → reading. Evidence: [App.tsx:198](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/App.tsx:198>), [App.tsx:306](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/App.tsx:306>).

3. **Partial reset specifies a warning but leaves live data state undefined.** Existing local state survives storage deletion and writes whole updated values back. If reset removes notes but fails on another key, retaining the current session could leave deleted notes visible and allow the next edit to persist them again. Define reconciliation of successfully cleared data, retained data, counts, and retry behavior before normal editing resumes. Evidence: [reset states](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/docs/launch/PLAN.md:181>), [hooks.ts:3](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/hooks.ts:3>).

4. **The new local identity does not extend to Home.** Home receives no reader name and hardcodes “GoodNewsToYou / Reader” in its profile entry. Editing the name would therefore update Profile while leaving the main entry unchanged. Specify shared name/default behavior across both screens, including session-only updates and reset. Evidence: [Home.tsx:105](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/components/Home.tsx:105>), [App.tsx:244](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/App.tsx:244>).

5. **The promoted journal journey omits unsaved-draft behavior.** Phase 2 describes saved and persistence-error states, but Escape or a backdrop click currently closes the editor and discards its draft without warning. Define whether dirty notes survive dismissal or require an explicit discard choice; distinguish unsaved drafts from saved-but-session-only notes. Evidence: [Journal.tsx:113](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/components/Journal.tsx:113>), [Modal.tsx:46](</Users/charlesfinney/Documents/Codex/Projects/New project/goodnews-daily-connect-local/src/components/Modal.tsx:46>).
